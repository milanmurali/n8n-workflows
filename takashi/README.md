Takashi is a lightweight AI-powered memory assistant built with n8n, Telegram, Supabase, and open-source LLMs.

It can:
- Save financial memories
- Query debts and balances
- Understand natural language
- Handle messy user input with fallback logic
- Persist data using Supabase

Example:

```text
I owe X 250
I paid X 100
How much do I owe X?
